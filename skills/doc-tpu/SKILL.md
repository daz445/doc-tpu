# docTPU — Готовый инструмент генерации отчётов ТПУ

## ВАЖНО: Это готовый CLI инструмент!

**НЕ ПИШИ СВОИ СКРИПТЫ ГЕНЕРАЦИИ.** Уже установлен готовый Python-пакет `doc-tpu`, который делает всё автоматически. Твоя задача — собрать данные у пользователя, создать нужные файлы и вызвать CLI-команды.

Полный путь к Python из скилла: `${CLAUDE_PLUGIN_ROOT}/.venv/Scripts/python.exe`
Полный путь к пакету: `${CLAUDE_PLUGIN_ROOT}/doc_tpu/`

## Workflow (строго по порядку)

### Шаг 0: Собрать данные у пользователя

Задай пользователю **одним сообщением** все вопросы из секции «Обязательные данные» ниже. Не используй значения по умолчанию — спроси явно. Если пользователь дал часть данных в первом сообщении — используй их и спроси только недостающие.

Пример формулировки:
> Для формирования отчёта мне нужно узнать:
> 1. Номер и тема лабораторной? (например: «Лабораторная №8: Стеганография»)
> 2. Название дисциплины?
> 3. Вариант? (если есть)
> 4. Номер группы?
> 5. Твоё ФИО?
> 6. ФИО и должность преподавателя?

### Шаг 1: Создать папку report/
```bash
mkdir -p report/images
```

### Шаг 2: Скопировать шаблон и логотип из скилла
```bash
cp "${CLAUDE_PLUGIN_ROOT}/template.snj" report/template.snj
cp "${CLAUDE_PLUGIN_ROOT}/assets/image1.png" report/images/image1.png
```

### Шаг 3: Создать report/static.json
Записать JSON с данными студента, преподавателя и информацией о лабораторной:
```json
{
  "student": { "full_name": "Иванов Иван Иванович" },
  "teacher": { "full_name": "Петров Пётр Петрович", "position": "доцент" },
  "group": "РИ-230901",
  "lab": {
    "title": "ЛАБОРАТОРНАЯ РАБОТА № 8",
    "subtitle": "СТЕГАНОГРАФИЯ",
    "discipline": "Информационная безопасность",
    "variant": "6"
  },
  "format": "docx",
  "template": "template.snj"
}
```

### Шаг 4: Создать report/content.md
Создать `report/content.md` — тело отчёта в формате Markdown. Подставь полученные от пользователя данные (номер лабораторной, дисциплину, тему) в заголовки и текст. Формат — обычный Markdown:

```markdown
# Цель работы
Изучить...

# Ход работы
1. Шаг первый...
2. Шаг второй...

# Результаты
Описание результатов...

# Выводы
В ходе работы было выполнено...
```

### Шаг 5: Сгенерировать документ
Выполни **строго эту команду** (не пиши свои скрипты!):
```bash
cd report && "${CLAUDE_PLUGIN_ROOT}/.venv/Scripts/python.exe" -m doc_tpu generate -b content.md -r static.json -p report.docx
```

### Шаг 5.5: Предпросмотр (если пользователь хочет проверить)
```bash
cd report && PYTHONPATH="${CLAUDE_PLUGIN_ROOT}" "${CLAUDE_PLUGIN_ROOT}/.venv/Scripts/python.exe" -m doc_tpu preview .
```
Покажи ссылку: `http://127.0.0.1:PORT`
На странице можно:
- Просмотреть отчёт в стиле ТПУ
- Перетаскивать и редактировать блоки
- Редактировать mermaid-диаграммы
- Экспортировать в .docx

### Шаг 6: Сообщить пользователю
Готово! Файл: `report/report.docx`

## Обязательные данные

| Поле | Описание | Пример |
|---|---|---|
| `lab.title` | Номер лабораторной | `ЛАБОРАТОРНАЯ РАБОТА № 8` |
| `lab.subtitle` | Тема лабораторной | `СТЕГАНОГРАФИЯ` |
| `lab.discipline` | Дисциплина | `Информационная безопасность` |
| `lab.variant` | Вариант (если есть) | `6` |
| `student.full_name` | ФИО студента | `Иванов Иван Иванович` |
| `teacher.full_name` | ФИО преподавателя | `Петров Пётр Петрович` |
| `teacher.position` | Должность преподавателя | `доцент` |
| `group` | Номер группы | `РИ-230901` |

## Структура отчёта

```
report/
├── template.snj     ← шаблон титульной (копия из скилла)
├── content.md       ← тело отчёта
├── static.json      ← данные студента/преподавателя
├── images/
│   └── image1.png   ← логотип ТПУ
└── report.docx      ← результат
```

Все файлы в `report/`. Не записывай ничего в корень рабочей директории.

## Спецификация форматирования

- Times New Roman 14пт, межстрочный 1.5
- Поля: 20/20/34/15 мм
- Заголовки 1-го уровня: 16пт, жирные
- Титульная страница с логотипом ТПУ (автоматически из шаблона)
- Нумерация страниц справа внизу, без номера на титульнике

## Список литературы (ГОСТ Р 7.0.100–2018)

- **Книга:** `Фамилия, И. О. Название / И. О. Фамилия. – Город : Издательство, Год. – Число с.`
- **Статья:** `Фамилия, И. О. Название статьи / И. О. Фамилия // Название журнала. – Год. – Т. X, № X. – С. X–X.`
- **Электронный ресурс:** `Название : [Электронный ресурс]. – URL: https://... (дата обращения: ДД.ММ.ГГГГ).`

## Частые ошибки

- **Нет `static.json`** — на титульной не будут ФИО
- **Файлы не в `report/`** — всегда создавай папку report/ и работай в ней
- **Пишешь свои скрипты** — НЕ НУЖНО. Уже есть `doc-tpu generate`, `doc-tpu preview`
